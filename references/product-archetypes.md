# 产品类型路由

先判断主类型，必要时附加一个次类型。分类只决定重点、样本覆盖和追问方式，不能替代证据。

## AIGC 创作工具

重点检查意图到结构化创作参数的转换；提示词、风格、角色/对象、场景、镜头或素材引用；模型、模式、清晰度、时长、成本和额度；小样、批量生成、局部修改、版本、重生成和最终合成；一致性、质量验证、安全拦截、失败退款和资产血缘；“生成完成”与可见资产、最终成品、可编辑状态是否一致。

## 通用执行 Agent

重点检查目标澄清、计划、执行、观察、修正和完成判定；工具权限、可逆性、审批门、幂等、重试和取消；长任务、异步状态、定时/监控、日志与用户接管；记忆与项目上下文边界；口头承诺、工具结果和真实外部状态是否一致；高风险动作如何限制授权。

## 对话陪伴类产品

重点检查人设、语气、关系阶段、主动性与连续性；长短期记忆、遗忘、纠错、隐私和跨会话一致性；情绪识别、回应、安全升级与危机处理；依赖风险、拟人化表达、用户控制和退出机制；付费与内容安全对关系体验的影响。

## 对话式专业助手

重点检查问题理解、信息收集、来源引用和输出可编辑性；专业知识、检索、工具、文件和工作区上下文；事实正确性、引用、版本和协作交接；结果如何进入用户真实工作流。

## 传统工作流 / SaaS

重点检查角色权限、对象生命周期、表单校验、审批、通知、批处理、导入导出、审计、集成和异常恢复。无 AI 证据时，模型层明确标记“不适用”。

## 平台、市场或社区

重点检查多边角色、供需匹配、内容/商品发现、交易或互动闭环、治理、信誉、审核、增长机制与数据网络效应。

## 硬件或软硬一体产品

重点检查设备配网、连接状态、离线/弱网、固件、传感器数据、权限、跨端同步、故障诊断和物理安全。

## 混合类型

使用“主类型决定主流程，次类型补充风险”。例如 AIGC + 执行 Agent 同时检查生成资产链与工具授权；陪伴 + 社区同时检查关系记忆与平台治理。

## 判断卡格式

| 字段 | 内容 |
|---|---|
| 主类型 | 证据支持的类型 |
| 次类型 | 可选 |
| 核心用户任务 | 用户要完成的事 |
| 输入—处理—输出 | 简述 |
| 决策权分配 | 用户决定 / 系统建议 / 系统自动执行 |
| 判断证据 | E01 起的证据编号 |
| 置信度 | 高 / 中 / 低 |
| 加重检查主题 | 3–8 项 |
